# Task 1.4

Given:
  a, b, c — three real numbers

Find:
  Avg — arithmetic mean of three numbers

Model:
  Avg = (a + b + c) / 3

Algorithm:
  1. Input a, b, c.
  2. Compute Avg = (a + b + c) / 3.
  3. Output Avg.
  4. End.

Tests:
  (1, 2, 3) -> Avg = 2
  (10, 20, 30) -> Avg = 20
  (0, 0, 6) -> Avg = 2
