# Task 1.1

Given:
  a > 0, b > 0 — sides of the rectangle (real numbers)

Find:
  P — perimeter
  S — area

Model:
  P = 2 * (a + b)
  S = a * b

Algorithm:
  1. Input a.
  2. Input b.
  3. Compute P = 2 * (a + b).
  4. Compute S = a * b.
  5. Output P, S.
  6. End.

Tests:
  (3, 4) -> P = 14, S = 12
  (1, 1) -> P = 4, S = 1
  (0.5, 100) -> P = 201, S = 50
