# Task 1.8

Given:
  P > 0 — initial deposit amount (real number)
  r > 0 — annual interest rate in percent (real number)

Find:
  A — total deposit amount after one year

Model:
  A = P * (1 + r / 100)

Algorithm:
  1. Input P, r.
  2. Compute A = P * (1 + r / 100).
  3. Output A.
  4. End.

Tests:
  (P = 1000, r = 10) -> A = 1100
  (P = 5000, r = 5) -> A = 5250
  (P = 200, r = 12) -> A = 224
