# Task 1.2

Given:
  r > 0 — radius of the circle/disk (real number)

Find:
  C — circumference of the circle
  S — area of the disk

Model:
  C = 2 * pi * r
  S = pi * r^2
  (where pi ≈ 3.14159)

Algorithm:
  1. Input r.
  2. Compute C = 2 * 3.14159 * r.
  3. Compute S = 3.14159 * r * r.
  4. Output C, S.
  5. End.

Tests:
  (r = 1) -> C ≈ 6.28, S ≈ 3.14
  (r = 5) -> C ≈ 31.42, S ≈ 78.54
  (r = 0.5) -> C ≈ 3.14, S ≈ 0.79
